How It Works

The 0/1 Knapsack Algorithm

Guarantees the globally optimal allocation in O(n×W) time via bottom-up tabulation.

01

Initialise Table

Create an (n+1)×(W+1) table. Row 0 and column 0 are all zeros — base cases for zero tasks or zero capacity.

02

Fill by Recurrence

For each task i and each capacity w: either skip the task or include it if it fits and improves profit.

03

Backtrack Solution

Walk backwards from dp[n][W]. Whenever dp[i][w] ≠ dp[i-1][w], task i was selected — subtract its resource.

Recurrence Relation
dp[i][w] = dp[i-1][w]                               // skip task i (always)
dp[i][w] = max( dp[i-1][w],
                dp[i-1][w - ri] + pi )        // include if r_i ≤ w
Time Complexity
O(n × W)
n tasks · W capacity units
Space Complexity
O(n × W)
Reducible to O(W) with 1-D rolling array
Optimality
Exact
Globally optimal — beats any greedy approach
Type
Pseudo-poly
Polynomial in n, exponential in bits of W
